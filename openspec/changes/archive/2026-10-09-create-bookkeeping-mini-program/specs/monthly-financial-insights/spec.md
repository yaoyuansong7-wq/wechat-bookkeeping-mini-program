# Spec Delta

## Purpose

将用户的账目按月份、日期和分类汇总为清晰的收支信息，帮助用户快速理解当月结余与主要支出去向。

## ADDED Requirements

### Requirement: 月度收支汇总
系统 SHALL 针对用户选择的自然月，分别合计收入与支出，并以收入减支出计算当月结余。

#### Scenario: 查看存在账目的月份
- **WHEN** 用户查看包含收入和支出账目的月份
- **THEN** 系统展示该月收入总额、支出总额以及两者之差形成的结余

#### Scenario: 查看没有账目的月份
- **WHEN** 用户查看不存在任何账目的月份
- **THEN** 系统将收入、支出和结余均展示为零

### Requirement: 统计随账目变化更新
系统 MUST 使用当前有效账目计算统计结果，使新增、修改或删除账目后的汇总与明细保持一致。

#### Scenario: 新增账目后刷新统计
- **WHEN** 用户成功新增所选月份内的一笔账目
- **THEN** 系统在下次展示统计时将该账目计入对应汇总

#### Scenario: 修改账目影响统计归属
- **WHEN** 用户修改账目的金额、类型、分类或日期
- **THEN** 系统在下次展示统计时按修改后的内容重新归入月份、日期和分类

#### Scenario: 删除账目后刷新统计
- **WHEN** 用户成功删除一笔账目
- **THEN** 系统在下次展示统计时不再计入该账目

### Requirement: 每日支出趋势
系统 SHALL 按发生日期汇总所选月份内每天的支出金额，并按日期顺序展示趋势。

#### Scenario: 查看每日支出趋势
- **WHEN** 用户打开某个月份的统计页
- **THEN** 系统展示该月每天的支出合计且不将收入计入支出趋势

### Requirement: 支出分类汇总
系统 SHALL 按分类汇总所选月份内的支出金额，并展示各分类金额及其占当月总支出的比例。

#### Scenario: 查看分类统计
- **WHEN** 所选月份存在支出账目
- **THEN** 系统按支出金额从高到低展示各分类的金额和占比

#### Scenario: 当月没有支出
- **WHEN** 所选月份不存在支出账目
- **THEN** 系统展示无支出统计的空状态且不计算分类占比

### Requirement: 金额显示规则
系统 SHALL 以人民币元显示金额并保留两位小数，汇总计算不得使用会产生可见浮点误差的金额表示。

#### Scenario: 展示含小数的汇总金额
- **WHEN** 汇总结果包含元以下金额
- **THEN** 系统以人民币符号和两位小数展示准确结果
