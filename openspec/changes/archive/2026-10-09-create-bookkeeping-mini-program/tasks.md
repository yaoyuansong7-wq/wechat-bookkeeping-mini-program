- [x] 2.1 定义账目类型、内置分类、账目输入与云端账目模型，并通过类型检查验证页面端和云函数端可共享这些定义

- [x] 3.4 为账目云函数添加跨用户访问测试，验证用户无法读取、修改或删除其他 OpenID 的账目
- [x] 3.5 实现月度统计云函数，仅聚合当前用户和指定月份的账目，并通过测试验证空月份及收入、支出、趋势和分类结果
