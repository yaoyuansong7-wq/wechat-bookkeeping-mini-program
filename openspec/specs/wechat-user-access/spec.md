# wechat-user-access Specification

## Purpose

确保微信用户能够无须单独注册即可进入个人账本，并保证云端账目始终只对其所属用户可见和可操作。

## Requirements

### Requirement: 微信身份登录
系统 SHALL 在用户进入小程序时通过微信身份建立有效的个人会话，无须用户创建额外的账号和密码。

#### Scenario: 首次进入小程序
- **WHEN** 用户首次打开小程序且微信身份验证成功
- **THEN** 系统建立该微信用户的个人会话并进入账本首页

#### Scenario: 再次进入小程序
- **WHEN** 已使用过小程序的用户再次打开小程序且现有身份仍然有效
- **THEN** 系统恢复该用户的个人会话并加载其云端账本数据

### Requirement: 登录失败反馈
系统 MUST 在无法识别微信用户身份时阻止访问个人账本，并向用户显示可重试的明确反馈。

#### Scenario: 微信身份验证失败
- **WHEN** 微信身份验证或云端会话建立失败
- **THEN** 系统不展示任何个人账目，并提示用户重新尝试登录

### Requirement: 用户数据隔离
系统 MUST 只允许当前已登录用户读取、创建、修改或删除归属于自己的账目数据。

#### Scenario: 读取个人账目
- **WHEN** 已登录用户请求查看账目或统计数据
- **THEN** 系统仅返回与该用户微信身份关联的数据

#### Scenario: 操作非本人账目
- **WHEN** 用户尝试修改或删除不属于自己的账目
- **THEN** 系统拒绝操作且不改变目标账目

### Requirement: 云端数据可恢复
系统 SHALL 使同一微信用户在重新进入小程序或更换设备后访问其已保存的云端账目。

#### Scenario: 更换设备后进入
- **WHEN** 用户在另一台设备上使用同一微信身份进入小程序
- **THEN** 系统加载该身份已有的云端账目数据
